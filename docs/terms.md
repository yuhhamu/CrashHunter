# CrashHunter 利用規約(第3版 2026年11月19日)

## 1. このソフトについて
CrashHunter は yuhhamu が無料で配布する、Mod に対応したサードパーティ製の Minecraft ランチャー(以下「ランチャー」。対応しているランチャーは README に記載)のインスタンスが落ちる原因を調べて直すためのソフトです。著作権は yuhhamu が持ちます(All Rights Reserved)。ソースコードは閲覧できるように公開しています。

CrashHunter は Minecraft 公式の製品ではなく、Mojang・Microsoft が承認したものでも、関与したものでもありません。ランチャーの開発元とも関係ありません。

## 2. 使用の許可

**次のことを許可します。**

- 個人利用・商用利用を問わず、無料で使うこと
- ソースコードを読むこと
- 不具合の報告、紹介記事・動画・スクリーンショットでの紹介

**次のことは禁止します(作者が個別に許可した場合を除きます)。**

- 改変、改変したものの作成と配布
- ソースコードの全部または一部を、ほかのソフトウェアに複製・流用すること
- 作者が指定した配布元([GitHub](https://github.com/yuhhamu/CrashHunter))以外での再配布やミラー
- CrashHunter の名前やアイコンを使って別のものを配ること

同梱しているほかのソフトウェアは、それぞれのライセンスに従います。

## 3. 保証しないこと
このソフトは現状のまま提供します。原因の特定や修正が正しいこと、ゲームやデータが壊れないこと、常に動くことは保証しません。

## 4. インスタンスの変更
原因特定・構成調整・自動修正は、Modの有効・無効の切り替え、Modやローダーのバージョン変更、ファイルの追加・削除を行います。元のインスタンスへの変更は取り消せるように記録しますが、大事なワールドや設定は事前にバックアップしてください。

## 5. 責任の範囲
このソフトの利用によって生じた損害(データの消失、ゲームやPCの不具合などを含みます)について、作者は責任を負いません。ただし、作者の故意または重大な過失による場合や、法令で責任を免れることが認められない場合は除きます。

## 6. 外部のサービスとMod
Modやローダーの取得には CurseForge・Modrinth・ランチャーが公開しているメタデータなどを使います。取得したファイルの扱いは、各サービスとModの作者が定める条件に従ってください。

## 7. CrashHunter Database
データの送信は任意で、初期値では何も送りません。送る内容と扱いは[CrashHunter データの取り扱い](https://github.com/yuhhamu/CrashHunter/blob/main/docs/database-privacy.md)のとおりです。

送ったデータについて、作者が次のことを行うことを許可したものとします。

- 集計し、ほかの利用者に配布データとして提供すること
- 集計をModの開発者に提供すること(端末IDと報告そのものは提供しません)
- 不正な送信を防ぐために保存・確認すること

虚偽の報告や、特定のModや個人を貶める目的での送信はしないでください。そのような報告は削除し、以後の受け付けを止めることがあります。

## 8. サービスの変更・停止
CrashHunter Database と更新の確認は、予告なく内容を変えたり、止めたりすることがあります。

## 9. 規約の変更
規約は変えることがあります。変えた規約は、このソフトとGitHubに載せた時点から適用します。利用者に大きく影響する変更のときは、次の起動時に表示し、改めて同意をお願いします。

## 10. 一部が無効な場合
この規約の一部が法令などで無効とされても、残りの部分は有効です。
